# AI-Powered-Journal
An AI-powered personal journal application built with Python and JavaScript. It automatically analyzes the mood of your daily entries and visualizes emotional health trends over time.

This repository contains an AI-Powered Personal Journal with Mood Analysis, a smart web application that tracks your daily entries, analyzes your emotional patterns using machine learning, and visualizes your mental wellness trends over time through an interactive dashboard. 
## Key Features  
+ Smart Journaling: Write and edit secure daily entries with rich-text support.
+ Mood Analysis: Automatically detects and tags the primary emotion of each entry using AI.
+ Trend Dashboard: Displays weekly and monthly charts of your emotional health.
+ Private and Secure: Keeps all personal reflections safe and encrypted.  
## Tech Stack
+ Frontend/Interface: JavaScript (HTML/CSS) 
+ Backend/AI Engine: Python (Flask/FastAPI & NLP Libraries)
